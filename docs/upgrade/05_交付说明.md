## 2. 破坏性变更（上游必须先读这段）

1. **`AUTH_ENABLED` 默认 `true`**：所有业务 API 需要 `Authorization: Bearer <token>`（或 `?token=`，供原生播放器用）。Flutter 端目前不带 token，**直接升级会全线 401**。本地开发请先在 `backend/.env` 写 `AUTH_ENABLED=false`（退化为 `?user_id=` 开发模式）；`/health` 与 `tts|asr /status` 始终公开。
2. **存储从文件切到 SQLite**：`data/users/**`、`data/characters/**`、`data/groups/**` 不再是真相源，改为 `data/roleplay.db`（WAL）。旧数据要跑一次性迁移脚本，否则新库是空的。
3. **`backend/app/store.py` 成为唯一 SQL 出口**：任何直接读写 `data/` 目录的旧代码路径都已删除；新增 `db.py`/`core/security.py`/`api/auth.py`/`api/sse.py`。
4. **群聊 WS 增加鉴权**：连接需带 `?token=`，失败关闭码 `4401`（无/坏 token）与 `4404`（群不存在或不可见）。
5. **内容安全默认开启**（`MODERATION_ENABLED=true`）：命中危机/未成年人相关类别时**不再调用模型**，直接回置顶话术（危机含热线），单聊输出侧命中会整体替换已流出的文本并落库替换版。这会让"贴边"用例的回复与旧版不同——若上游有自己的审核策略，可置 `MODERATION_ENABLED=false` 关闭（不建议：关闭后危机干预一并失效）。词表分级、`MINOR_MODE`、`MODERATION_LLM`、`MODERATION_LEXICON_PATH` 见 `04_实施记录.md` §2.7。
6. **`/metrics` 默认不可见**：`METRICS_ENABLED` 默认 false 且 `METRICS_TOKEN` 默认空 → 路由返回 404；两者都配了才生效，取 token 走 `X-Metrics-Token` 头或 `?token=`。指标只在进程内累计，重启清零，不引入 Prometheus 依赖。
7. **CORS 不再下发凭证**：`allow_credentials` 由 true 改 false（`CORS_ALLOW_ORIGINS` 仍默认 `*`）。前端只用 `Authorization` 头，不依赖 cookie，因此行为不变；若上游后续要接 cookie 会话，需同时改来源白名单。
8. **新增 8 个环境变量**：`LOG_LEVEL`、`CORS_ALLOW_ORIGINS`、`METRICS_ENABLED`、`METRICS_TOKEN`、`MODERATION_ENABLED`、`MODERATION_LLM`、`MINOR_MODE`、`MODERATION_LEXICON_PATH`，全部有安全默认值，不配也能起。
