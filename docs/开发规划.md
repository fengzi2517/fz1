# AI 角色扮演聊天工具 - 开发规划文档

> 版本：v1.0 | 日期：2026-11-10 | 状态：待执行

## 一、总体路线图

```
M0 ──────────────► M1 ──────────────► M2
对话+记忆+设置     语音交互          多角色+群聊
(核心可用)         (体验增强)         (产品化)
```

| 阶段 | 目标 | 核心交付 | 依赖 |
|------|------|---------|------|
| **M0** | 跑通单人对话闭环，记忆机制可用 | 后端记忆系统 + Flutter 聊天界面 + 左滑设置 | 无 |
| **M1** | 加入语音输入输出，升级记忆检索 | ASR/TTS 集成 + 向量语义检索（可选） | M0 完成 |
| **M2** | 多角色管理 + 群聊机制 | 角色库 + 群聊会话 + 多角色记忆 | M1 完成 |

## 二、M0 阶段规划（核心可用）

### 2.1 目标
- 单人对话跑通，LLM 能遵循角色人设回复
- 记忆机制闭环：对话历史 → 摘要蒸馏 → 长期记忆 → 按需检索
- Flutter 界面：对话框 + 左滑设置 + 角色导入

### 2.2 后端任务

| 编号 | 任务 | 说明 | 工时 |
|------|------|------|------|
| B-01 | 项目脚手架 | FastAPI 工程、配置管理、目录结构 | 0.5d |
| B-02 | LLM Adapter | OpenAI 兼容协议封装，支持流式输出 | 0.5d |
| B-03 | MemoryService | md/jsonl 文件读写、按日期解析、关键词检索 | 1d |
| B-04 | CharacterService | 角色人设导入解析、CRUD | 0.5d |
| B-05 | ChatService | Prompt 组装、SSE 流式对话、recall 工具调用 | 1d |
| B-06 | DistillService | 会话结束异步蒸馏、摘要生成、去重追加 | 0.5d |
| B-07 | API 层 | chat/characters/memory 接口 + 错误处理 | 0.5d |

**后端交付物：**
- 可启动的 FastAPI 服务
- `/api/chat/send`（SSE 流式）
- `/api/chat/end`（触发蒸馏）
- `/api/characters`（CRUD）
- `/api/memory/*`（记忆查看）

### 2.3 前端任务

| 编号 | 任务 | 说明 | 工时 |
|------|------|------|------|
| F-01 | Flutter 工程初始化 | 项目结构、依赖、主题 | 0.5d |
| F-02 | 聊天界面 | 消息列表、气泡、输入框、发送 | 1d |
| F-03 | SSE 流式渲染 | 接收 token 逐字渲染回复 | 0.5d |
| F-04 | 左滑设置面板 | 模型选择、Temperature、记忆开关 | 0.5d |
| F-05 | 角色导入页 | 文本粘贴/文件导入、人设预览 | 0.5d |
| F-06 | 状态管理 | 会话状态、消息状态、错误处理 | 0.5d |

**前端交付物：**
- 可运行的 Flutter App（Android）
- 聊天主界面（消息气泡 + 输入框）
- 左滑设置面板
- 角色导入页面

### 2.4 联调与测试

| 编号 | 任务 | 工时 |
|------|------|------|
| T-01 | 端到端对话测试 | 0.5d |
| T-02 | 记忆机制验证（写入 → 蒸馏 → 检索） | 0.5d |
| T-03 | 边界情况测试（空记忆、长文本、网络异常） | 0.5d |

### 2.5 M0 验收标准

- [ ] 能导入角色人设，AI 回复符合人设
- [ ] 多轮对话有上下文连续性
- [ ] 会话结束后，长期记忆 md 文件有新内容追加
- [ ] 对话中提到"记得""上次"等，AI 能检索并引用相关记忆
- [ ] 左滑设置面板可切换模型、调节参数
- [ ] 首字响应延迟 < 2s（取决于 LLM API）

| B-V01 | ASR 接口 | 接入语音识别（可选：阿里云/讯飞/Whisper） | 1d |
| B-V02 | TTS 接口 | 接入语音合成，支持角色音色配置 | 1d |
| B-V03 | 语音文件管理 | 临时音频存储、清理 | 0.5d |

### 3.4 M1 验收标准

## 五、技术依赖与准备

### 5.1 开发环境

| 工具 | 用途 | 安装位置 |
|------|------|---------|
| Python 3.11+ | 后端运行 | D 盘 |
| Flutter SDK | 前端开发 | D 盘 |
| Android Studio / VS Code | IDE | 已有 |
| pip 依赖 | fastapi, uvicorn, httpx, jieba, pyyaml | D 盘 venv |

### 5.2 LLM API 准备

- 获取一个 OpenAI 兼容的 API Key（DeepSeek / 智谱 / 月之暗面等）
- 配置到后端 `.env` 文件
- M0 阶段先用一个模型，后续在设置面板可切换

### 5.3 文件存储

- 记忆文件存储在 `backend/data/` 目录下
- 该目录加入 `.gitignore`，不提交到版本库

## 六、风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| LLM API 不稳定 | 对话失败 | 配置备用模型，超时自动切换 |
| 记忆文件膨胀 | 检索变慢 | 定期归档旧记忆，限制单文件大小 |
| recall 误触发 | 回复不相关 | 优化规则关键词 + LLM 决策双重保险 |
| 人设遵循度低 | 体验差 | 优化 System Prompt，人设放在高优先级 |
| Flutter 环境配置 | 开发阻塞 | 提前验证 Flutter doctor 通过 |

---

## 七、开发顺序建议

```
Step 1: 后端脚手架 + LLM Adapter（B-01, B-02）
Step 2: MemoryService 核心（B-03）
Step 3: CharacterService（B-04）
Step 4: ChatService + 流式对话（B-05, B-07）
Step 5: DistillService（B-06）
Step 6: Flutter 聊天界面（F-01, F-02, F-03）
Step 7: 左滑设置 + 角色导入（F-04, F-05, F-06）
Step 8: 联调测试（T-01, T-02, T-03）
```
