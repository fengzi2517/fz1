## 项目快照（S0 盘点）

- 仓库：https://github.com/fengzi5422/role_play （本地 `/home/zz/projests/role_play`，HEAD `2be800d`）
- 技术栈：
  - `backend/`：Python FastAPI，约 2900 行；模块含 chat / conversations / characters / groups / memory / asr / tts API，services 含 memory / distill / group / idle / chat / character / asr / tts，LLM adapter + prompts
  - `frontend/`：Flutter（Web/移动端），providers（chat / conversation / group / voice / settings）+ services（api / conversation_api / group_api / group_ws / voice）
  - `app/`：Android 壳工程（Kotlin，仅 MainActivity）
  - `tools/whisper/`：Whisper/Parakeet 本地 ASR 可执行文件（Windows）
  - `docs/`：已有中文设计文档 5 篇（概要设计、详细设计、开发规划、M1 语音交互规划、M2 群聊开发记录）
- 关键观察（待 S1 验证）：后端已存在 memory_service + distill_service（记忆蒸馏）、idle_service（闲置主动消息）、group_service（600 行，群聊编排核心）
